# sky/

Precomputed sky data consumed by the three.js client. Regenerated by `scripts/regenerate_sky.py` after `rag/vectors.json` updates.

## Files

- **`coords.json`** — UMAP-3D positions per inscription. One entry per AXN: `{axn, position: [x, y, z], mass, origin}`.
- **`edges.json`** — lineage edges connecting inscriptions to their sources (when sources are themselves corpus entries). `[{from_axn, to_axn, kind}]` where `kind` is `derives_from | transforms | references`.
- **`planets.json`** — fixed positions for the seven planetary bodies (Mercury, Moon, Mars, Sun, Saturn, Venus, Jupiter) per AXN-0237's substrate-role assignments. These positions are constants, not corpus-derived.

## Coordinate system

Inscriptions inhabit a sphere of radius 100 centered at origin. Planets sit at radius 300, fixed positions arranged according to AXN-0237's planetary topology. Camera defaults to position `(0, 0, 150)` looking at origin; this is the Sabbath-mode default view.

## Compact JSON

All files use the alexanarch compact-JSON discipline (`indent=None, separators=(',',':'), ensure_ascii=False`). The client loads them as static assets via fetch; gzip on Vercel handles compression.
