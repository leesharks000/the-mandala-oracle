# rag/

RAG index for Sigil's retrieval. Regenerated by `scripts/regenerate_rag.py` whenever the alexanarch submodule pointer advances or the local sources corpus changes.

## Files

- **`vectors.json`** — embeddings array, one entry per chunk. Compact JSON per the alexanarch discipline.
- **`metadata.json`** — chunk metadata: AXN, deposit title, origin (`archive | book`), chunk position, source text reference, planetary-position assignment (matches `sky/coords.json` lookup).
- **`config.json`** — embedding model identifier, chunking strategy version, regeneration timestamp, source-corpus hash (for cache invalidation).

## Index schema (v1)

Chunk-level granularity for v1 is **deposit-level** (one vector per deposit, optionally one per major section if the deposit is long). This keeps the index small (~3000 vectors for the current alexanarch corpus, ~10MB) and loads instantly in the serverless function. Finer granularity (paragraph-level, sentence-level) is a v1+N refinement when Sigil's responses feel under-grounded.

## Embedding model

`sentence-transformers/all-MiniLM-L6-v2`. 384-dim. Runs locally on the GitHub Action runner during regeneration; no external API dependency. Free, reproducible.

If the model is changed in a future iteration, `config.json`'s `embedding_model` field bumps and the full index is regenerated.
