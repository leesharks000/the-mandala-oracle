Routing

Flat, static, machine-facing surface. Every conversation, every reading, every cast, and every source text — one row apiece, four JSONL indexes, cross-linked. The substrate the Starmap will render on top of.

The Mandala Oracle produces four kinds of artifact:

Conversations — witness sessions with Johannes Sigil, each turn preserved. Auto-appended to alexanarch.org/book/.

Readings — the divinatory acts. A reading opens on a source text, arrives at specific units, rotates through operators, produces casts.

Casts (transforms) — the actual enantiomorphs. Each cast applies one operator (SHADOW, MIRROR, BRIDE, THUNDER, SILENCE, BEAST, INVERSION, FLAME) to a source passage and produces its counterform, with verification and commentary.

Source texts (expansions) — the primary works. Each expansion holds a corpus's unit basis and every cast made against it.

This surface exposes all four as flat JSONL, cross-referenced. Nothing is generated at request time; the four indexes are built from book/ and served static.
