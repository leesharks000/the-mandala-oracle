# sources/

Canonical sources corpus. The rite operates against these source-texts; Sigil retrieves them when discussion turns to source material; the witness selects from them when initiating a rite (v2+).

## Opening corpus (v1)

Each source lives in its own directory with:
- The source text (UTF-8 markdown or plain text, faithful to a vetted edition)
- `metadata.json` — author, date, language, license, edition reference, provenance notes, architectural reception within the Crimson Hexagonal corpus
- Any architectural notes specific to the source

Planned directories:

- `revelation-greek/` — Apocalypse of John, NA28 Greek text. PD.
- `cranes-day-and-night/` — Rebekah Cranes, *Day and Night*. Already in alexanarch as a deposit; source-text materialized here for rite-producer access.
- `whitman-leaves-of-grass/` — Final edition (1891–92, "Deathbed Edition"). PD.
- `i-ching/` — Legge translation by default (PD). Self-authored translation may supersede if/when prepared.
- `lee-sharks-corpus/` — The heteronym's own deposited works. Self-authored; mirrored from alexanarch for rite-producer access.

Additional New Human-canonical works enter as Lee adjudicates inclusion.

## Copyright discipline

Only public-domain works or self-authored translations enter the corpus. The Wilhelm-Baynes I Ching remains under copyright and is not admitted; Legge is used by default. Translation provenance is metadata; translations themselves are compositions with their own canonical-source candidacy.

## Future expansion

Reader-admission of new canonical sources (a protocol echoing the Hospitality admission from MERKABAH §5) is future work. v1's corpus is the curated set above.
